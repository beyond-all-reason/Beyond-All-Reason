# Authored map overrides

These small Lua data files come from Zero-K commit
`e358dac2ca2f9163c5290f700d74466016305b04` under its GPL v2-or-later
terms. Their relative paths identify the originals in
https://github.com/ZeroK-RTS/Zero-K/tree/e358dac2ca2f9163c5290f700d74466016305b04.
They retain that game’s authored starts, metal spots and Living Lands lighting
when composing the shared example. Original map archives retain their authors’
terms. No map media is stored here.

The packer prefers metadata inside each source map, then this override root;
other compositions can supply their own `--game-dir` metadata root. OpenAI Codex
assisted with packaging these existing files; the data was not generated by AI.
